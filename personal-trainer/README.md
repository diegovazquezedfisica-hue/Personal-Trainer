# Personal Trainer — Archivos del proyecto

## Estructura de carpetas

```
personal-trainer/
├── index.html              ← Landing page pública
├── dashboard.html          ← Panel admin entrenadora
├── assets/
│   ├── img/
│   │   ├── logo.png               ← Logo principal
│   │   └── ejercicios/
│   │       ├── prensa.png
│   │       ├── hip-thrust.png
│   │       └── (más ejercicios...)
│   └── audio/
│       └── workout-mix.mp3        ← Música del player
└── README.md
```
